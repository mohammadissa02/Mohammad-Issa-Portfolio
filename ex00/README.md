# Systems Console — Personal Portfolio

A personal portfolio built with HTML, CSS, and JavaScript, using the original dark Systems Console visual style.

## Sections
- About
- Skills & tools
- Small web exercises and projects
- Interests
- Contact

The Education section and PhishGuard featured project have been removed. The page is kept as a simple personal portfolio rather than a CV; the original visual style, theme toggle, navigation, and contact-form demo are preserved.

## Run locally
Open `index.html` in a browser.

## Before publishing
- Replace `assets/profile-placeholder.svg` with your own profile image if you want.
- Replace `your.email@example.com` with your preferred email address.
- The contact form is a front-end demo and does not send messages.
